Here's a Python helper function that clamps a value to the range 1-100:

```python
def clamp(n):
    """
    Clamp a value to the range 1-100.
    
    Args:
        n: The value to clamp (int or float)
        
    Returns:
        The clamped value (int or float)
    """
    return max(1, min(100, n))
