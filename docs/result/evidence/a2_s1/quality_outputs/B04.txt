Here's a simple FastAPI endpoint that returns `{'ok': True}`:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"ok": True}
```

This creates a GET endpoint at the root path (`/`) that returns the specified JSON response. To run it, save this code in a file (e.g., `main.py`) and execute it with `uvicorn main:app --reload`.
