• **Data Type Mismatch**: A FastAPI request validation failure occurs when the data sent in a request doesn't match the expected data type defined in the Pydantic model or type hints. For example, if a field is defined as `int` but the client sends a string like "hello", FastAPI raises a `ValidationError` with details about the type mismatch.
