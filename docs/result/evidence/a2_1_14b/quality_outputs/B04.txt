Certainly! Below is a simple example of a FastAPI endpoint that returns `{'ok': True}`.

```sh
pip install fastapi
```

Then, you can create a Python file (e.g., `main.py`) with the following content:

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    return {"ok": True}
